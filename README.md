## Projektid

### Kuukülv

Kuukülv on Expo ja React Native'iga tehtud eestikeelne külvikalender Androidile, iOS-ile ja veebile. Äpp soovitab kuufaasi järgi külvipäevi Eesti kasvutingimustes. Lisaks on äpis külviplaanid ja meeldetuletused, külvipäevik, ilma- ja mullaprognoos ning aiavaade. Kalender ja päevik töötavad ka võrguühenduseta.

Projekt asub eraldi hoidlas: [katlintootmaa-cmd/Kuukulv](https://github.com/katlintootmaa-cmd/Kuukulv)
